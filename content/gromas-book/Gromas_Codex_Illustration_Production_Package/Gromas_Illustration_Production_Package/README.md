# Gromas and the Gobbledygooks — Illustration Production Package

This package contains the complete production brief, character/world bible, exact prompts for all 14 interior story spreads, anchor prompts, cover and spot-art prompts, locked manuscript, YAML manifests, and preflight checklists.

## Start here

1. Read `00_MASTER_CODEX_BRIEF.md`.
2. Run **PROOF mode** first.
3. Approve the character/object anchor sheets.
4. Review the 14-spread thumbnail contact sheet.
5. Only then run **PRODUCTION mode**.

## Most important files

- `02_14_SPREAD_PROMPTS.md` — all 14 complete prompts in one document
- `prompts/spreads/` — one paste-ready prompt file per spread
- `book_manifest.yaml` — exact pagination, text, asset filenames, and production constants
- `character_manifest.yaml` — naming and continuity data
- `manuscript_locked.txt` — exact edited story text
- `decision_log.md` — locked choices and the single Chet/Gromas speaker ambiguity

## Final book plan

- 6 x 9 inch portrait Hardcover Casewrap
- 32 interior pages
- 14 story spreads, pages 4–31
- 19 publication illustration assets: 14 spread masters, one cover-wrap art system, and four interior spot/vignette assets
- Premium Color recommended for the image-rich interior

The supplied Gromas reference is included at `references/gromas_reference.jpeg`.
