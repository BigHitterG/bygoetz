# Production Quality-Control Checklist

## Anchor approval

- [ ] Gromas front/side/back views match the user reference.
- [ ] Gromas expressions retain the same eye spacing, mouth, digits, feet, and strand silhouette.
- [ ] Chet reference is supplied or the provisional design is explicitly approved.
- [ ] Frontliners, Electricians, and Lookouts share species anatomy.
- [ ] Spinette resting/compressed/spinning states are approved.
- [ ] Great Power Supply low/empty/charging states are approved.
- [ ] Human black shoe and Bobby are approved.
- [ ] World scale cutaway is approved.

## Per-spread visual checks

- [ ] Story action matches the assigned stanza(s).
- [ ] Gromas appears only where intended and is not duplicated accidentally.
- [ ] Gromas identity matches the approved model sheet.
- [ ] Chet and troop roles remain recognizable.
- [ ] Great Power Supply state is correct.
- [ ] Spinette state is correct.
- [ ] Time of day and lighting follow the visual arc.
- [ ] Humans are only as visible as directed.
- [ ] Bobby appears only in the morning-routine sequence unless intentionally echoed.
- [ ] Toast motif appears naturally and does not overwhelm the scene.
- [ ] No key face, hand, gauge, shoe contact, or coil lies in the gutter.
- [ ] Text-safe zones are low-detail and high-contrast.
- [ ] No generated words, letters, labels, logos, or readable numerals.
- [ ] No extra limbs, wrong digits, fused hands, or floating tools.
- [ ] No horror, weapon-like Spinette, unsafe electricity, or threatening humans/dog.

## Typography checks

- [ ] Manuscript text matches `manuscript_locked.txt` character for character.
- [ ] Each quatrain remains intact.
- [ ] Poetic line breaks are preserved whenever possible.
- [ ] No automatic hyphenation.
- [ ] Text is at least 0.5 inch inside trim with additional inside-gutter room.
- [ ] Font is embedded in the PDF.
- [ ] Text remains readable over art in grayscale and on a printed proof.
- [ ] No visible page numbers on story pages.

## Interior PDF preflight

- [ ] Exactly 32 pages.
- [ ] Every page is 6.25 x 9.25 inches.
- [ ] Single-page layout, not spreads.
- [ ] 300 PPI images; no image exceeds 600 PPI unnecessarily.
- [ ] sRGB color profile.
- [ ] Fonts embedded or converted appropriately.
- [ ] Transparency flattened where required.
- [ ] No crop, registration, trim, or bleed marks.
- [ ] No password/security.
- [ ] Title page on page 1; copyright on page 2.
- [ ] No more than two consecutive blank pages; ideally none.
- [ ] Page count divisible by four.

## Cover preflight

- [ ] Final Lulu custom casewrap template was downloaded after page count and paper were locked.
- [ ] Cover PDF is one integrated page: back cover, spine, front cover.
- [ ] No guessed spine width.
- [ ] No spine text for the 32-page Global Distribution edition.
- [ ] All critical text and faces respect the hardcover casewrap safety area.
- [ ] Background extends through wrap and bleed.
- [ ] Official barcode zone is clear if using an ISBN.
- [ ] Title/byline on cover exactly match metadata and title page.

## Printed proof review

- [ ] Order and inspect a physical proof before approval.
- [ ] Check dark teal detail for plugging/muddiness.
- [ ] Check pale text zones for sufficient contrast.
- [ ] Check gutter loss on all 14 spreads.
- [ ] Check Gromas skin/strand greens for consistency.
- [ ] Check power-glow yellows and copper for print shift.
- [ ] Check small verse type for comfortable read-aloud use.
- [ ] Check cover fold/hinge alignment and barcode clearance.
