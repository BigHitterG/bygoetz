# Gromas and the Gobbledygooks — Codex Start Here

This folder is reserved for the book illustration project.

## Package location

Upload this file into this same folder:

`Gromas_Codex_Illustration_Production_Package.zip`

## First Codex task

Read this file, then:

1. Extract `content/gromas-book/Gromas_Codex_Illustration_Production_Package.zip`.
2. Move the contents of the archive's inner `Gromas_Illustration_Production_Package/` directory directly into `content/gromas-book/`, preserving all subfolders.
3. Verify that these files exist:
   - `content/gromas-book/00_MASTER_CODEX_BRIEF.md`
   - `content/gromas-book/01_CHARACTER_WORLD_BIBLE.md`
   - `content/gromas-book/02_14_SPREAD_PROMPTS.md`
   - `content/gromas-book/references/gromas_reference.jpeg`
4. Do not modify any Basil files or unrelated website code.
5. Read `00_MASTER_CODEX_BRIEF.md` and run **PROOF mode only**.
6. Stop after producing the anchor sheets, fourteen low-resolution spread thumbnails, contact sheets, and continuity report for human review.

Do not begin final high-resolution illustrations or assemble the final book PDF during the first run.
